# コーディング規約

> このファイルは CLAUDE.md からは自動参照されません。Claude が必要時に Read します。

## 全般

- 命名は明示的に。略語より説明的な名前を選ぶ
- コメントは「なぜ」だけ書く。「何を」はコードで読ませる
- 1 関数 1 責務。ネストは 3 段以内を目安

## コミットメッセージ

```
<type>: <一行サマリ>

<本文・なぜこの変更が必要かを書く>
```

type は `feat` / `fix` / `refactor` / `docs` / `chore` / `test` のいずれか。

## ブランチ

- `main` — 安定版
- `feat/<name>` — 機能追加
- `fix/<name>` — バグ修正

## テスト

- 新機能には最低 1 件のテスト
- バグ修正には再現テスト
- モックは外部 I/O 境界のみ。内部ロジックはモックしない

## プロジェクトごとの上書き

`projects/<name>/docs/conventions.md` がある場合はそちらを優先。
