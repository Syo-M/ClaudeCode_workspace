# Components

既存 UI コンポーネントの参照資料を置きます。Claude Design はここを読んで「既存の見た目に寄せた」生成をします。

## 何を置くか

- スクリーンショット(`button-primary.png` など)
- HTML/CSS スニペット(`button.html`)
- React/Vue コンポーネントの抜粋

## ファイル命名

`<種類>-<状態>.<拡張子>` を推奨:

- `button-primary.png`
- `card-elevated.html`
- `nav-mobile.png`

## 注意

- 大量の画像を入れるとリポジトリが膨らむ。重要なもの 10〜20 点に絞る
- 機微情報を含むスクショは置かない
