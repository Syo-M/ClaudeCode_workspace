# Design System(投入用原本)

Claude Design に「組織のデザインシステム」として読み込ませる素材一式。

## ファイル一覧

- `brand-guide.md` — 全体のブランド方針(声質・トーン含む)
- `colors.md` — カラーパレット(主・副・アクセント)
- `typography.md` — フォント・サイズ・ウェイト・行間
- `components/` — 既存 UI 部品のスクリーンショット or コード抜粋
- `tokens/` — JSON 形式のデザイントークン(任意・将来用)

## Claude Design への投入方法

A. **コードベース URL を渡す**(推奨)
   GitHub の URL を Claude Design に貼り付けると、リポジトリ全体から自動抽出されます。

B. **個別ファイルをアップロード**
   `system/` 配下のファイルをドラッグ&ドロップ。

C. **既存のプロトタイプ画像を渡す**
   スクリーンショットを混ぜると、既存の見た目に寄せたデザインを生成しやすい。

## 更新時の手順

1. ここのファイルを更新してコミット
2. Claude Design 側の Organization 設定 → デザインシステム → 「リミックス」で再生成
3. 全プロジェクトに反映を確認
