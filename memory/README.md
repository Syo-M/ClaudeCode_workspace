# Memory(参考)

このディレクトリは **記事の構成例に合わせた参照プレースホルダ** です。

## 実際の auto memory 保存先

Claude Code の auto memory は、リポジトリ内ではなく **ユーザーホーム配下** に保存されます:

```
~/.claude/projects/<エンコードされたプロジェクトパス>/memory/
├── MEMORY.md           # 索引(常時 200 行まで読み込まれる)
└── <topic>.md          # 個別の記憶ファイル
```

このプロジェクトの場合の正確なパスは、Claude に「memory の保存先を教えて」と聞けば返ってきます。

## 記憶の種類

- `user` — ユーザーの役割・好み・知識レベル
- `feedback` — 修正・確認されたアプローチ(理由つき)
- `project` — 進行中の作業・締切・関係者
- `reference` — 外部システム(Linear, Slack など)へのポインタ

## 操作

- 保存: 「○○を覚えておいて」と依頼するか `/save-memory` を呼ぶ
- 確認: 「memory を見せて」または直接 `~/.claude/projects/.../memory/` を Read
- 削除: 「○○の memory を消して」

## このディレクトリ内に何か置くか?

通常は不要です。リポジトリ固有の **不変な前提知識** (e.g. ドメイン用語集)を残したい場合のみ、ここに `.md` で置いてください。
auto memory とは別系統で、Claude は明示的に Read した時のみ参照します。
