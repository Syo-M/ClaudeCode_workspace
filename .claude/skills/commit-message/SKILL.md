# Commit Message Generator

## いつ使うか

- ユーザーが「コミットして」「commit して」と依頼した時
- ステージ済みの変更があり、メッセージだけ提案してほしい時

## 手順

1. `git status` と `git diff --cached` を読む
2. `docs/conventions.md` のコミット規約セクションを読む(必要時のみ)
3. 以下のフォーマットでメッセージを組み立てる:

   ```
   <type>: <一行サマリ(50 字以内)>

   <なぜこの変更が必要か(任意)>
   ```

4. `type` は `feat` / `fix` / `refactor` / `docs` / `chore` / `test` から選ぶ
5. ユーザーに提案を見せ、承認を得てから `git commit` を実行

## 出力

- 提案メッセージを 1 つ
- ユーザーが承認したら `git commit -m "..."` を実行
- 承認なしでコミットしない

## 注意

- 複数の独立した変更が含まれる場合は、コミット分割を提案する
- `.env` などのシークレットを含むファイルがステージされていたら警告
