# サブエージェント

このディレクトリに `<name>.md` を置くと、`Agent` ツールから `subagent_type: <name>` で呼び出せます。

## 命名規則

- 役割を表す名詞または動詞句(`explorer`, `reviewer`, `test-runner`)
- 1 ファイル 1 エージェント

## フォーマット

```markdown
---
name: <name>
description: <一行説明>
tools: Read, Bash, Grep  # 使えるツールを絞る(コンテキスト節約)
---

# <Agent Name>

<役割の詳細・出力フォーマット指定>
```

## 使いどころ

- **探索系**: 広範囲のコード走査(メインのコンテキストを汚さない)
- **レビュー系**: 独立した視点での確認(親の判断バイアスから切り離す)
- **検証系**: テスト実行・ビルド確認(長い出力を要約して返す)

ビルトインの `Explore` / `Plan` で足りるうちは無理に作らない。
