---
description: 直近の会話から学んだことを memory に保存
---

直近の会話を振り返り、将来のセッションで役に立つ情報を memory に保存してください。

保存対象の判断基準:
- ユーザーの役割・好み・知識レベル(user memory)
- 修正・確認されたアプローチ(feedback memory)
- 進行中のプロジェクト・締切・関係者(project memory)
- 外部システムへのポインタ(reference memory)

保存しないもの:
- コードから読めば分かる構造・規約
- git log で追える履歴
- 一時的な作業状態

追加対象: $ARGUMENTS

何を保存したか(または保存対象なしの理由)を 3 行以内で報告してください。
